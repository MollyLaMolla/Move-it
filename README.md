# 🚚 Move It

A clean and modern landing page for a fictional moving company.  
Built entirely with **HTML, CSS, and Bootstrap**, this project focuses on layout, responsiveness, and UI design.

---

## 🧠 Overview

Move It is a simple front‑end website created to practice layout structure, Bootstrap components, and responsive design.  
The page includes a hero section, service highlights, a carousel, and a footer — all styled using Bootstrap 5.

This project was part of my early front‑end learning journey, helping me understand how to build structured, professional‑looking landing pages quickly.

---

## 🔥 Features

- 🧭 **Responsive navigation bar** with dropdown menu  
- 🏠 **Hero section** with headline, description, and call‑to‑action buttons  
- 📦 **Service highlights** with icons and descriptions  
- 🖼️ **Image carousel** with three slides  
- 📬 **Footer** with multiple link sections  
- 🎨 Fully styled using **Bootstrap 5**  
- 📱 100% responsive on all screen sizes  

---

## 🎨 Design Highlights

- Clean, modern layout  
- Bootstrap grid system for easy responsiveness  
- Icons and illustrations for a friendly, professional look  
- Buttons styled with Bootstrap utilities  
- Carousel with indicators and navigation arrows  

---

## 🛠️ Tech Stack

**Frontend Only:**
- HTML  
- CSS  
- Bootstrap 5  

No JavaScript logic — only Bootstrap’s built‑in components.
